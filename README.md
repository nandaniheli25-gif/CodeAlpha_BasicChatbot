🔗 CodeAlpha_BasicChatbot


🔗 Project overview

This project is a Basic Rule-Based Chatbot developed using Python that simulates a simple conversation between a user and a computer. The chatbot interacts through a command-line interface and responds to predefined inputs such as greetings, common questions, expressions of gratitude, and farewell messages.


The project demonstrates fundamental Python concepts including functions, conditional statements, loops, user input handling, and string manipulation. It serves as a beginner-friendly introduction to chatbot development while providing an interactive way to understand decision-making and conversational logic in programming.

🔗 Features

 . Rule-based chatbot
 
 . Interactive chat
 
 . Greetings support
 
 . Common replies
 
 . Ignores letter case
 
 . Empty input check
 
 . Continuous chat
 
 . Python-based
 
 . Simple interface
 
 . Beginner-friendly project
